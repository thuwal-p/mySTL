# MySTL

**A from-scratch implementation of C++ STL containers and utilities.**

MySTL is a custom implementation of commonly used C++ Standard Template Library (STL) containers, built from scratch to understand their internal working, memory management, and time complexities.

### Features

- **Sequence Containers:** Vector, Deque, List
- **Container Adaptors:**
  - Stack — built using Vector
  - Queue — built using Deque
- **Associative Containers:** Set, Map (using balanced search trees)
- **Unordered Containers:** Unordered Set, Unordered Map (using hash tables)
- **Iterators:** Custom iterator implementations
- **Algorithms:** Common STL-style algorithms

### Tech Stack

`C++17` `GoogleTest` `CMake`
